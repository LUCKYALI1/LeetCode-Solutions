# Minimum Moves to Equal Array Elements (Increment Only) | O(N) Time & O(1) Space

# Intuition

In this problem, the only permitted operation is to **increase** any element by $1$. This constraint fundamentally changes how the optimal target value is determined:

1. **Monotonicity of Operations:** Because elements can only increase, no number can ever reach a target value $T$ that is smaller than its initial value.
2. **Lower Bound on the Target:** To make every element equal to $T$, $T$ must satisfy:
   $$T \ge nums[i] \quad \forall \; i \in [0, n - 1]$$
   Therefore:
   $$T \ge \max(nums)$$
3. **Minimizing Total Operations:** The total number of moves needed to raise all elements to a common target $T$ is:
   $$\text{Total Moves} = \sum_{i=0}^{n-1} (T - nums[i]) = n \cdot T - \sum_{i=0}^{n-1} nums[i]$$
   Because $n > 0$, this function is strictly increasing with respect to $T$. To minimize the total moves, we must choose the smallest possible valid $T$:
   $$T = \max(nums)$$

Unlike problems allowing both increments and decrements (where the median is optimal), when restricted to increments only, the target is strictly the maximum element of the array.

# Approach

1. **Handle Edge Cases:** If the array is empty, $0$ moves are required.
2. **Find the Maximum Value:** Traverse the array once to find the maximum element, $M = \max(nums)$.
3. **Accumulate Moves:**
   * Iterate through the array and compute the deficit for each element: $M - nums[i]$.
   * Add each deficit to a running accumulator `total_moves`.
4. **Prevent Integer Overflow:** The sum of differences can exceed standard $32$-bit signed integer limits ($2^{31} - 1$), especially if the array size $N \approx 10^5$ and element range is large. Use a $64$-bit integer (`long long` in C++, regular integers in Python 3, or `BigInt` / standard safe floats in JavaScript) for the accumulator.

# Detailed Dry Run

### Input: `nums = [1, 2, 4, 7]`

* Number of elements $n = 4$
* Maximum element $M = \max([1, 2, 4, 7]) = 7$

| Step | Element ($nums[i]$) | Operation Needed ($7 - nums[i]$) | Moves Added | Cumulative Moves |
| :--- | :--- | :--- | :--- | :--- |
| 1 | $1$ | $7 - 1$ | $6$ | $6$ |
| 2 | $2$ | $7 - 2$ | $5$ | $11$ |
| 3 | $4$ | $7 - 4$ | $3$ | $14$ |
| 4 | $7$ | $7 - 7$ | $0$ | $14$ |

**Final Output:** $14$

# Complexity

* **Time complexity:** $\mathcal{O}(N)$
  Finding the maximum value takes a single pass ($\mathcal{O}(N)$), and calculating the total sum of differences takes a second pass ($\mathcal{O}(N)$). Both can also be merged into a single pass.
* **Space complexity:** $\mathcal{O}(1)$
  No auxiliary data structures are allocated; only scalar accumulator variables are used.

# Code
``` cpp []
#include <vector>
#include <algorithm>

class Solution {
public:
    long long minMoves(std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        // Find the maximum element
        int max_val = *std::max_element(nums.begin(), nums.end());
        long long total_moves = 0;

        // Sum the differences
        for (int x : nums) {
            total_moves += (static_cast<long long>(max_val) - x);
        }

        return total_moves;
    }
};
```

``` python []
class Solution:
    def minMoves(self, nums: list[int]) -> int:
        if not nums:
            return 0

        max_val = max(nums)
        
        # In Python, integers have arbitrary precision and will not overflow
        total_moves = sum(max_val - x for x in nums)
        
        return total_moves
```


``` javascript []
/**
 * @param {number[]} nums
 * @return {number}
 */
var minMoves = function(nums) {
    if (!nums || nums.length === 0) {
        return 0;
    }

    let maxVal = -Infinity;
    for (const num of nums) {
        if (num > maxVal) {
            maxVal = num;
        }
    }

    let totalMoves = 0;
    for (const num of nums) {
        totalMoves += (maxVal - num);
    }

    return totalMoves;
};
```
